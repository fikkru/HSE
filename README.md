CVE-2020-11022

Краткое описание

CVE-2020-11022 — уязвимость типа Reflected XSS (межсайтовый скриптинг), связанная с некорректной обработкой пользовательского ввода, который отражается в HTML-ответе без экранирования.
Атакующий может внедрить JavaScript-код, который выполнится в браузере пользователя.
