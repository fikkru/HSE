Анализ событий информационной безопасности
Описание проекта
Этот проект предназначен для анализа событий информационной безопасности, загруженных из JSON-файла. Код автоматически извлекает типы событий, анализирует их распределение и строит визуализацию.

Основные функции
1. Загрузка данных
Чтение JSON-файла с событиями безопасности

Автоматическое преобразование в pandas DataFrame

2. Обработка данных
Извлечение типа события из поля signature (берется первое слово до пробела)

Преобразование временных меток в формат datetime

3. Анализ и визуализация
Подсчет количества событий каждого типа

Построение столбчатой диаграммы распределения

Добавление числовых значений над столбцами для наглядности
